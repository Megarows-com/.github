# MegaRows

Open and plot huge CSV, Excel, MATLAB and LabVIEW TDMS files in the browser. Files are read on the device and never
uploaded.

- **Plot millions of rows:** [CSV plotter](https://megarows.com/plotter?utm_source=github&utm_medium=org-profile) and
  [large CSV viewer](https://megarows.com/large-csv-viewer?utm_source=github&utm_medium=org-profile), beyond Excel's
  1,048,576-row limit.
- **MATLAB without MATLAB:** [MAT file viewer](https://megarows.com/mat-file-viewer?utm_source=github&utm_medium=org-profile)
  and [MAT to CSV](https://megarows.com/mat-to-csv?utm_source=github&utm_medium=org-profile) for v4, v6, v7 and v7.3.
- **Test and measurement formats:** [TDMS viewer](https://megarows.com/tdms-viewer-online?utm_source=github&utm_medium=org-profile),
  Parquet, HDF5, spectrograms and FFTs.

## Free sample data

[sample-mat-files](https://github.com/Megarows-com/sample-mat-files): synthetic MATLAB .mat files in every version, with
a CSV of each signal, for testing MAT readers and converters. CC0.
